# AIFP-3 Governance

AIFP-3 evolves through public AIFP Improvement Proposals.

## Principles

1. Global passport identity is independent from any blockchain.
2. The issuer key is controlled by AiFinPay and never delegated to the holder.
3. Holder recovery cannot rewrite issuer-protected identity history.
4. Every wallet binding requires direct ownership proof.
5. Status and revocation fail closed across AiFinPay services.
6. Relying parties receive the minimum data required for their decision.
7. Specification, implementation and deployment status are reported separately.

Normative identity/security changes require a protocol maintainer, an independent security reviewer and a migration plan. Privacy-impacting changes also require a privacy review.
